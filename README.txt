PROJET WEB — TARIQ AL TAWBA
Extraire le ZIP, puis ouvrir index.html dans Chrome ou Edge.
8 scènes / 64 secondes / 1280×720. Aucun serveur ni dépendance externe.
Animation Canvas : caméra virtuelle, fondus, particules, lumière et vignette.
Les personnages restent des images fixes : pas de mouvement articulé ni de lip-sync.
La narration facultative utilise les voix du navigateur (voix arabe selon installation).
Export vidéo WebM sans audio, en temps réel. Garder l'onglet actif.
Les images des anges sont des représentations artistiques, non des descriptions authentifiées.
